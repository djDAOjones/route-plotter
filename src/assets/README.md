# Bundled visual assets

`drone-head.png` is the owner-approved HEAD-01 route-head preset. It was
generated with OpenAI's built-in image tool on 2026-08-26, then resized to
512 × 512 while preserving its alpha channel. The source prompt requested a
right-facing, top-down four-rotor drone with a charcoal body, white keyline,
clean transparent background and no text, scenery, shadow or watermark.

The build inlines the PNG in both application bundles. It is deliberately not
part of `public-assets.json`, which governs the separately copied example
background images.
