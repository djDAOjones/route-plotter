# UI-08 — A toggle in the Background card to hide the background

## Intent

The owner, 2026-10-18, verbatim: "for the backlog, the background section needs a toggle to hide the background - this could be the next feature added". Asked where the toggle should hide the background, the owner picked "Everywhere (Recommended)", whose option read: "One switch in the Background card hides the image while editing, in playback and in exports. The export checkbox follows it, so what you see is what you export." Asked where it goes, the owner picked "Top of Current (Recommended)". Today the Background card cannot hide the image: it holds Darken / lighten, Zoom and Upload. Reveal's Background → Hide applies only in Preview mode, while Edit mode always shows the image; Video settings → Include in export → Background image acts only on video exports. (The filing question called Reveal's Hide "playback only"; it is Preview mode, playing or paused.)

## Acceptance criteria

The filing session's proposals, for a plan to confirm or replace with the owner:

- The Background card has a toggle that shows or hides the background image. A new project starts with it shown.
- Hidden, the image is not drawn in Edit or Preview mode, playing, paused or scrubbing, or in MP4, WebM and HTML exports. Routes, dots, labels and the camera draw as before.
- The toggle and Include in export → Background image are one setting: changing either changes both, and both read the same after undo, redo, save and reopen.
- Hiding never drops the image: showing it again brings back the same image, zoom and overlay without a new upload, and the image is still saved with the project.
- One change of the toggle is one undoable step. It has a visible label, a 44 px target and a state announced to screen readers, and it works from the keyboard (WCAG 2.2 AAA, the UI standards).
- One name for one thing: the plan settles how the toggle reads beside Reveal's Background → Hide and the export checkbox, so an author never meets two words for the same state.
- A save made before UI-08 with its export checkbox ticked opens looking as it did. One with the checkbox unchecked showed its image in Edit mode but left it out of video exports; one setting cannot keep both, so the plan decides which it opens with.
- No new dependency.
