# AI-01 — AI-editable saves

## Intent

The owner, 2026-10-15, verbatim: "how feasible is it to export a save from route plotter, have an AI agent edit a file for you, and upload that back into the app for video export / alteration? this way users could describe what they want and have it constructed, or at least seeded, for them". He also asked "to what extent would it help if the save had Described parameters so another chat based AI can take the zip and construct a new route / save / animation. Including description of all the options / features available. it could also include a Instruction set for the AI." After the filing session's analysis he said: "add to the backlog as a medium term future feature". An author exports a package that a chat-based AI can read: the project, a description of every option and a set of instructions. The author describes the scene they want, the AI builds or edits it, and the app opens the result for playback, further editing and export.

## Acceptance criteria

The filing session's proposals, for a plan to confirm or replace with the owner:

- Before any app change, a hand-built package for one bundled example is tried in at least two chat AIs on a fixed set of requests. The results decide whether to build, and the requests become the feature's test set.
- An export produces the package: instructions for the AI; a schema of the save giving each field's meaning, units, range and visible effect; the current project; the background with a labelled grid of image coordinates; and a plain-language summary of the scene.
- The schema's ranges, allowed values and defaults are generated from the checks a project passes as it opens, so the schema cannot drift from the format. Only the descriptions are written by hand.
- The AI returns only the project's JSON, as a file or as pasted text. The app checks it as it checks any project, lists what changed, and applies it as one step that undo reverses, keeping the current background and images.
- Unknown fields and values are reported, not silently replaced by defaults.
- No new dependency without the owner's decision.

## Notes

- 2026-10-15 — The filing session's analysis, read from the code at b0e8838; on 2026-10-16 its line references and crowd checks were rechecked at 5daf698, after parts F and G. No AI-edited file was run through the app.
  - In its favour: `project.json` is plain JSON, with positions as fractions of the image and options as readable words. A waypoint missing fields takes defaults, so an AI can write a sparse one. A project that fails its checks is refused with a plain-language message an author can paste back to the AI. Import is hardened against untrusted files: its structure, numeric ranges, colours, sizes and resource limits are checked before a project opens.
  - In its way today: the ZIP import refuses any file it does not expect, though it skips directory entries (`src/services/ImageAssetService.js` (:864)). So guide files cannot travel inside a save, a ZIP of the enclosing folder has no top-level `project.json`, and a macOS re-zip's metadata files under `__MACOSX/` would probably be refused (untested). Chat AIs without code execution cannot build a ZIP. Mistyped option words pass silently: a waypoint keeps an unknown value, since `validate` checks position only (`src/models/Waypoint.js` (:501)), and an emitter's unknown lifecycle mode falls back to its default (`src/models/Emitter.js` (:315)). Numbers are checked against ranges; since CROWD-08 parts F and G, the group settings and Final whistle are also checked strictly for type and range. The format is still changing under CROWD-08 and will change again in v4.
  - Descriptions belong in a schema beside the save, not inside it. Inline, they would multiply its size, count against the import's text and node limits, risk being edited by the AI and go stale in old saves.
  - Likely use: high for bulk edits, restyling, timing, variants, translated labels and crowd tuning from a description, whose settings are abstract and fiddly by hand; medium for laying out a route from places named on the map, using the grid; low for precise shapes; none for judging motion, which the AI cannot see.
  - Proposed timing: after CROWD-08 ships, with or after MERGE-01, since v4 redefines the format and a schema-first save would serve the package, the help and the checks from one source. The session also raised an in-app box that calls an AI service directly, for the plan to weigh; it would bring keys, cost and privacy questions to a static site.
