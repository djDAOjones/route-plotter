How these numbers are counted
  • An item is one piece of work on the project backlog, such as a feature, a fix or a review. Items differ in size: the editor shell is one item, and so is a small defect fix.
  • An item is done when it has been built, checked and merged into the main code.
  • "In progress" means the item is marked so on the backlog, or has its own branch of work open.
  • "Needs sign-off" means the item waits on testing on real devices, such as an Android phone or a screen reader, or on the decision to declare v4.0.
  • The chart counts everything on the backlog, including parked ideas.
  • This page is rebuilt from the project's record each time the app is published. Item names are reworded in plain English from that record.
