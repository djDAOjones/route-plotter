Dot Crowd Navigator

Draw a network of nodes and edges over a map, then simulate crowd flow through the network.

Quick start

  1. Load a background image (drag-drop, or File → Example Backgrounds)
  2. Click on the map to add nodes
  3. Double-click nodes to cycle: normal → entry → exit
  4. Shift-click from one node to another to draw an edge
  5. Hit Play in the Simulation panel to see dots flow

Editing

  • Click a node or edge to select & edit properties
  • Drag a node to reposition it
  • Delete / Backspace — remove selection
  • Escape — deselect

View

  • Scroll wheel — zoom in/out (centered on cursor)
  • ⌘ / Ctrl + drag, or middle-click drag — pan
  • F — reset view to fit

Simulation

  • Space — toggle play / pause
  • Set node type to Entry for spawning, Exit for collection
  • Higher edge weight attracts more dots at junctions

File & History

  • ⌘S / Ctrl+S — save project as JSON
  • ⌘O / Ctrl+O — open project file
  • ⌘Z / Ctrl+Z — undo
  • ⌘⇧Z / Ctrl+Shift+Z — redo
